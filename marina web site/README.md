# Marina Nargile Web

POS’tan bağımsız e-ticaret vitrini (Vite + React + TypeScript).

## Çalıştırma

**Kolay yol:** proje kökündeki `Marina-Web-Baslat.bat` dosyasına çift tıkla  
(veya `marina web site\Marina-Web-Baslat.bat`).

Tarayıcı otomatik açılır: http://localhost:5174

**Manuel (Windows PowerShell — ExecutionPolicy engeli varsa `npm.cmd`):**

```powershell
cd "G:\Site_ve_Uygulamalar\UYGULAMALAR\Marina Nargile orj\marina web site"
npm.cmd install
npm.cmd run dev
```

## Notlar

- Katalog mock data (`src/data`)
- Sepet ve demo siparişler `localStorage`
- Üyelik placeholder (gerçek auth yok)
- Domain placeholder: marinanargile.com
