Mobil APK bu klasorde tutulur ama PC Setup paketine GOMMEZ.

Dosya adi:
  marina-pos-mobile.apk

Derleme:
  cd mobile
  eas build -p android --profile preview

Kurulu PC'de QR ile telefona vermek icin APK'yi kopyalayin:

  %APPDATA%\Marina Nargile POS\data\mobile\marina-pos-mobile.apk

(Klasoru yoksa olusturun.) Sonra Marina POS'ta "Baglantiyi ac" → APK indir QR.

Gelistirme (dev) icin bu klasordeki APK da yeterlidir (build/mobile).
